PADSwitcher 1.21.0 làm app phản hồi ngay, đổi tài khoản tức thì và tự cập nhật được.

- **Không còn phải đợi:** thao tác trên một tài khoản không chặn tài khoản khác, và chỉ
  nút đang chạy mới chờ. Đăng nhập trên trình duyệt không khóa ứng dụng.
- **Kéo thả tài khoản:** kéo thẻ để sắp xếp ở Codex và Kaggle, hoặc dùng Alt+↑/↓.
- **Cập nhật trong ứng dụng:** Cài đặt → Phiên bản kiểm tra, tải, đối chiếu checksum rồi
  cài đặt. Shortcut tự chuyển sang bản mới; bản cũ vẫn nằm trên máy.
- **Giao diện thống nhất:** mọi trang dùng chung kích thước thẻ, nút, ô nhập và nhãn.
- **Đổi tài khoản ngay:** có hiệu lực từ lần gọi model tiếp theo, giống như khi hết
  quota. Bước đang trả lời vẫn chạy nốt; các phiên khác không bị chặn.
- **Retry mặc định của Codex chạy đủ:** lỗi mạng thoáng qua không còn dừng lượt.
- **Mở VS Code trước cũng được:** PADSwitcher tự chạy trong khay rồi kết nối, trừ khi
  bạn đã tắt kết nối trong ứng dụng.
- **Nhật ký kết nối:** `events.jsonl` chỉ ghi loại sự kiện và lý do, không có nội dung
  hội thoại, token hay mã tài khoản.

Lưu công việc, thoát bản cũ từ khay hệ thống, mở bản mới rồi Reload Window trong VS Code
một lần. Hội thoại và tài khoản đã lưu được giữ.

Kiểm tra dùng engine Codex thật, tài khoản giả và model loopback; không dùng quota thật.
Việc VS Code đôi khi tự reload chưa xác định được nguyên nhân. Bản portable chưa ký số,
đi kèm checksum SHA-256.

---

This release makes the app respond immediately, switches accounts at once and adds
in-app updates. Work on one account no longer blocks another, and only the button that
started an action waits. Browser sign-in does not lock the app.

Drag account cards to reorder them in Codex and Kaggle, or use Alt+Up/Down. Settings →
Version checks, downloads, verifies the release checksum and installs; shortcuts move
to the new version and the old file stays on disk. All pages share one set of
measurements for cards, buttons, fields and labels.

A selected account applies from the next model request, like a quota rotation, without
blocking other sessions. Native Codex retries run to their full default budget. Opening
Codex in VS Code first starts PADSwitcher in the tray, unless the connection was turned
off. `events.jsonl` records event types and reasons only.

Save work, exit the old version from the tray, launch the new portable and reload the
VS Code window once. Conversations and saved accounts are kept. Validation uses real
native engines with synthetic accounts and loopback replies; it consumes no real quota.
The cause of occasional automatic VS Code reloads remains unknown. The executable is
unsigned and includes a SHA-256 checksum.
