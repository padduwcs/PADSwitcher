PADSwitcher 1.20.0 đưa các nâng cấp lõi Unix.7 sang Windows và bổ sung kết nối Codex desktop.

- Sửa tự chuyển tài khoản liên tiếp, xử lý streaming thiếu header và tránh gửi lặp bước model có kết quả không rõ.
- Thêm **Codex trong desktop**: dùng tài khoản chung, tiếp tục hội thoại cũ, giữ tools/plugin qua named pipe Windows có quyền riêng tư.
- Hiển thị trạng thái tự chuyển ở Tài khoản và Kết nối; giữ bố cục gọn ở cửa sổ nhỏ.
- Tạo môi trường Python Kaggle riêng, tự tìm Codex trong VS Code Insiders/Cursor/Windsurf và dùng thư mục home cho workspace mới.
- Cập nhật runtime và bổ sung kiểm tra chính file portable trước khi phát hành.

Tải `PADSwitcher-1.20.0-Windows.exe` và file `.sha256` bên dưới. Lưu công việc,
thoát bản PADSwitcher cũ từ khay hệ thống rồi mở bản mới; dữ liệu cũ được giữ lại.
Bản portable chưa ký số. Kiểm tra SHA-256 trước khi mở.

Kết nối desktop là tùy chọn. Lần đầu phải thoát hẳn ChatGPT/Codex desktop rồi
mở lại qua PADSwitcher và chờ **Đang kết nối**. Phần giao thức native, lịch sử,
resume và MCP đã qua kiểm tra tự động; kiểm chứng GUI trên một phiên Windows
thông thường đã đóng desktop vẫn cần nghiệm thu thủ công. Lịch sử ChatGPT thông
thường không chuyển giữa tài khoản. Không tự dùng reset credits.

---

This release brings the Unix.7 routing improvements to Windows, adds opt-in
local Codex desktop integration, private named-pipe MCP transport, managed Kaggle
Python environments, broader native discovery and clearer account-fallback UI.

Regression coverage includes 14 completed native turns, 12 quota fallbacks,
four steers and 14 unique disposable file writes, plus uncertain-stream fault
cases, original credential preservation and real portable executable startup.

Fully quit the existing desktop for its first connection. Ordinary installed-GUI
acceptance remains manual; native account routing, history/resume and MCP protocol
coverage are automated. The unsigned Windows portable includes a SHA-256 file.
