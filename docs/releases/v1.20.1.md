PADSwitcher 1.20.1 sửa lỗi mở Codex Desktop có âm báo nhưng không hiện cửa sổ.

- Helper hỗ trợ lệnh đọc policy khởi động của Desktop mới và giữ nguyên kết quả từ backend Codex.
- Mở GUI ở chế độ hiển thị; kiểm tra policy và chờ kết nối thực sự trước khi báo thành công.
- Hiển thị lỗi rõ ràng khi khởi động thất bại, backend dừng hoặc quá thời gian chờ.
- Đã kiểm tra ứng dụng Desktop cài trên Windows: cửa sổ xuất hiện, kết nối gateway, giữ hội thoại và tiếp tục sau một lỗi quota mô phỏng trên backend dùng chung với GUI.
- Kiểm tra native liên tiếp: 14 lượt, 12 lần chuyển quota, bốn lần bổ sung chỉ dẫn và 14 lần ghi file duy nhất; restart/resume và MCP cũng qua kiểm tra.

Tải `PADSwitcher-1.20.1-Windows.exe` cùng file `.sha256`. Lưu công việc,
thoát PADSwitcher và ChatGPT/Codex Desktop từ khay hệ thống, mở bản PADSwitcher
mới rồi chọn **Kết nối → Codex trong desktop → Mở desktop qua PADSwitcher**.
Dữ liệu và đăng nhập gốc được giữ. Bản portable chưa ký số.

Kiểm tra dùng tài khoản giả và model loopback; không cố tiêu hết quota thật.
GUI được khởi chạy thực tế, còn yêu cầu model được điều khiển qua native RPC
trên cùng backend trong lúc GUI đang kết nối. Phạm vi này không bao gồm tự động
nhập nội dung vào mọi thành phần GUI hoặc chuyển lịch sử ChatGPT thông thường.

---

This patch fixes desktop launches that played an alert without opening a window.
The helper now forwards the real native startup policy, launches the GUI visibly
and waits for an interactive connection before reporting success.

The installed Windows desktop passes startup/window/handshake checks, existing
thread resume and synthetic quota fallback on its backend while the GUI remains
connected. Native continuity covers 14 turns, 12 quota fallbacks, four steers and
14 unique marker writes. Startup reads preserve network policy and authentication.

Fully quit the old PADSwitcher and desktop before using the new portable. Model
fixtures use synthetic accounts and loopback replies. The unsigned executable
includes a SHA-256 checksum.
