# Be Vietnam Pro

Unmodified static fonts from the Google Fonts distribution, downloaded 2026-10-03:

- BeVietnamPro-Regular.ttf (400)
- BeVietnamPro-Medium.ttf (500)
- BeVietnamPro-SemiBold.ttf (600)
